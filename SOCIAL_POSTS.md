## Original safety-tip posts

1. **A padlock is not a trust badge.** HTTPS encrypts the connection, but you still need to verify the complete domain. Check suspicious URLs: https://armaanshashvat2014-dot.github.io/github-protect/suspicious-link-checker/
2. **The final file extension matters.** `invoice.pdf.exe` is an executable, not a PDF. Learn why: https://armaanshashvat2014-dot.github.io/github-protect/security-guides/double-file-extensions/
3. **Unexpected urgency is a warning sign.** Messages that demand immediate payment, passwords or one-time codes deserve independent verification: https://armaanshashvat2014-dot.github.io/github-protect/scam-message-checker/
4. **Do not run an unfamiliar EXE to “see what it does.”** Verify its source, complete filename, signature and hash first: https://armaanshashvat2014-dot.github.io/github-protect/security-guides/check-exe-before-opening/
5. **A browser-store listing is not a permanent guarantee.** Review what an extension can read or change: https://armaanshashvat2014-dot.github.io/github-protect/chrome-extension-permission-checker/
6. **Fake download buttons often appear inside advertisements.** Navigate through the verified publisher website before installing: https://armaanshashvat2014-dot.github.io/github-protect/security-guides/fake-download-websites/
7. **Chrome's “Not secure” warning is about the connection.** Avoid sending passwords or payment information through an unsafe page: https://armaanshashvat2014-dot.github.io/github-protect/security-guides/chrome-not-secure-warning/
8. **A SHA-256 hash identifies an exact file copy.** It is useful only when compared with a hash published by a trusted source: https://armaanshashvat2014-dot.github.io/github-protect/sha-256-file-checker/
9. **ZIP archives can contain executable files.** Inspect the contents before opening anything unexpected: https://armaanshashvat2014-dot.github.io/github-protect/zip-file-safety-checker/
10. **QR codes can hide destinations.** Preview and inspect the decoded URL before visiting it: https://armaanshashvat2014-dot.github.io/github-protect/qr-code-safety-scanner/
11. **A familiar logo proves very little.** Check the sender and full domain independently: https://armaanshashvat2014-dot.github.io/github-protect/suspicious-link-checker/
12. **Do not disable security because a download page tells you to.** Obtain the software from its verified publisher instead: https://armaanshashvat2014-dot.github.io/github-protect/security-guides/fake-download-websites/
13. **Powerful permissions should match the extension's purpose.** A simple tool should be able to explain why it needs broad access: https://armaanshashvat2014-dot.github.io/github-protect/chrome-extension-permission-checker/
14. **If you entered a password on a suspicious page, act through the real service.** Change it, review sessions and enable two-step verification: https://armaanshashvat2014-dot.github.io/github-protect/emergency-security-guide/
