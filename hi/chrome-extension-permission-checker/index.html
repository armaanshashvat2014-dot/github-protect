Chrome Extension Permission चेकर

Extension permissions तय करती हैं कि browser extension क्या access कर सकता है। manifest.json चुनें या permissions paste करके जोखिमपूर्ण access पहचानें।

Checker खोलें

यह क्या जाँचता है

  • सभी websites की access
  • history, cookies और tabs
  • downloads, clipboard और location
  • debugger और native messaging

इस्तेमाल कैसे करें

  1. नीचे Checker खोलें दबाएँ।
  2. माँगी गई link, text या file चुनें।
  3. Result और हर कारण ध्यान से पढ़ें।
  4. महत्वपूर्ण download को official source से verify करें।
महत्वपूर्ण सुरक्षा सूचना: यह checker दिखाई देने वाले संकेतों से निर्णय लेने में मदद करता है। Safe score पूरी सुरक्षा की guarantee नहीं है। Official source और publisher अलग से verify करें।
