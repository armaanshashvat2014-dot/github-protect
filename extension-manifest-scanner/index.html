Permissions that deserve attention

All-sites access

<all_urls> or broad host patterns let an extension interact with many pages. The access should clearly match its purpose.

Browsing data

History, tabs and cookies can reveal sensitive activity. Only trusted extensions should receive them.

Download control

The downloads permission can view or manage browser downloads and should have a clear reason.

Native messaging

This allows communication with software installed on the computer, making publisher trust especially important.

A permission warning is not proof of malware. Safe extensions can need powerful access, but they should explain why.
