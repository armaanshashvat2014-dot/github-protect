Browser Hijacking

Browser hijacking describes unwanted changes to search, homepage, new tabs or redirects—often caused by an extension or bundled software.

Common signs

  • The default search engine or homepage changes without approval.
  • Searches redirect through unfamiliar websites.
  • Unknown extensions return after being disabled.
  • Pop-ups appear on many unrelated pages.

Safe recovery

  1. Review extensions and remove ones you do not recognize.
  2. Restore the browser’s search and startup settings.
  3. Review site notification permissions.
  4. Update the browser and trusted security software.
  5. If changes return, ask a qualified technician to inspect the device.
