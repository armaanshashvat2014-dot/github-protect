Spyware

Spyware is software that secretly gathers activity or information without clear, meaningful permission.

Possible warning signs

  • Unknown software or extensions appear unexpectedly.
  • Browser search, homepage or permissions change without approval.
  • Pop-ups and redirects continue across unrelated websites.
  • An extension requests access far beyond its stated purpose.

Safer actions

  1. Review installed applications and browser extensions.
  2. Remove items you do not recognize using official system controls.
  3. Update the operating system and browser from built-in settings.
  4. Use trusted security software already installed on the device.
