Fake Update Alerts

Fake update pages imitate browser or system notices to persuade users to download an unsafe installer.

Warning signs

  • The alert appears inside an unfamiliar website instead of browser settings.
  • It uses extreme urgency, flashing warnings or countdowns.
  • It immediately downloads an executable or disk image.
  • It asks you to disable security controls.
  • The domain does not belong to the browser or software publisher.

Update safely

  1. Close the page without downloading anything.
  2. Open the browser or application menu.
  3. Use its built-in About or Update option.
  4. For system updates, use Windows Update or macOS System Settings.
