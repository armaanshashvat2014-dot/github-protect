# Five-Minute Tester Checklist

Use the live site: https://armaanshashvat2014-dot.github.io/github-protect/

1. Open the homepage on your normal browser.
2. Find one tool without using browser search.
3. Test only with non-private sample information.
4. Read the full result and note any confusing wording.
5. Try the Share, Security Guides and notification controls.
6. On mobile, check whether buttons fit and text remains readable.
7. Report the page, browser, operating system, expected result and actual result.

Do not submit private files, passwords, one-time codes, account recovery information or personal conversations.
