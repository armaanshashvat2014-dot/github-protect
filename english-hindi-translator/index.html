Features

  • English to Hindi translation
  • Hindi to English translation

Privacy

Translation is performed on-device where the browser supports it. If unavailable, the app can open a blank external translator, but it will not automatically transfer your pasted text.

Accuracy note: Automatic translations can misunderstand context, names or technical terms. Review important translations before using them.
