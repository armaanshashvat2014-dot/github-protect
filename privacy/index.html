Privacy-first security

Privacy

Your security inputs stay private. Optional analytics is separate from scanning and begins only after you choose to allow it.

Security information that is not sent to Google Analytics

  • Selected filenames and file contents
  • File hashes and scan results
  • Pasted emails, scam messages and extension manifests
  • Passwords or password-checker input
  • Security AI questions and answers
  • Downloaded reports and checklist contents

Optional anonymous analytics

If you select Accept analytics, GitHub Protector loads Google Analytics using measurement ID G-5SW1S6NYZK. It may measure page views, approximate country, device/browser type, referring website and general engagement such as page navigation.

Google Analytics may use browser storage or cookies for measurement. Advertising signals and advertising personalization are disabled by the site configuration.

If you select Continue without analytics, the Google Analytics script is not loaded. The choice is stored locally in your browser so the site remembers it.

Change your choice

Use the Analytics settings button at the bottom of any tracked page. Declining after previously accepting stops future analytics loading after the page refreshes. Clearing browser storage also removes the saved choice.

Accounts and uploads

The public browser tools do not require a GitHub Protector account. Selected-file checks use browser APIs on the device; the app does not upload file contents to a GitHub Protector database.

Analytics provider

Optional measurement is provided by Google Analytics. Google processes analytics information under its own terms and privacy policies. Do not enter private information into page URLs or public form fields.
