Browser extension

Windows & Mac installation

Press Download
The extension-only ZIP will download.
Extract it
Right-click the ZIP and choose Extract All.
Open extensions
Open your browser’s extension page and enable Developer mode:
chrome://extensions · edge://extensions · brave://extensions · opera://extensions.
Load it
Press Load unpacked and select the extracted folder.
Press Download
The extension-only ZIP will download.
Unzip it
Double-click the ZIP, or use Open With → Archive Utility.
Open extensions
Open your browser’s extension page and enable Developer mode:
chrome://extensions · edge://extensions · brave://extensions · opera://extensions.
Load it
Press Load unpacked and select the extracted folder.
Important: Install the extension separately in every browser you want protected. Select the extracted folder containing manifest.json—never the ZIP itself. Firefox and Safari are not supported by this package yet.
