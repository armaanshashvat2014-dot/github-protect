Local file scan

Checks filenames, extensions, Windows PE headers, architecture, entropy, size, and creates a SHA-256 fingerprint. It does not upload or execute files.

Drop files here

What it detects

Risky executable types, hidden double extensions, malformed Windows PE files, unusual section counts, high entropy, misleading names, and mismatched signatures.

Privacy

Scanning uses browser APIs on your device. The app has no analytics, account, file uploads, or remote database.

Browser limitations

No background device scan

Browsers cannot inspect files you do not select.

No automatic removal

The app cannot quarantine or delete system files.

No guaranteed verdict

Unknown malware may look harmless to basic checks.

Demo, not a full antivirus: If a file is marked “No obvious risk,” that does not prove it is safe. Keep your operating system and trusted antivirus protection enabled.
