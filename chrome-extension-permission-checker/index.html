Chrome Extension Permission Checker

Browser-extension permissions determine what an extension can access. Upload a manifest.json file or paste its permissions to identify access that deserves careful review.

Open the checker

What it checks

  • Access to all websites
  • Browsing history, cookies and tabs
  • Downloads, clipboard and location access
  • Debugger and native-messaging permissions

How to use it

  1. Open the working checker below.
  2. Enter the requested link or select the requested file.
  3. Read the score and every listed reason.
  4. Verify important downloads through the official source.
Important safety note: This checker helps you make a decision using visible warning signals. A safe score is not a guarantee. Verify the official source and publisher separately.
