# Contributing to GitHub Protector

Thanks for helping improve the project.

## Useful contributions

- Report a broken button or unclear result.
- Suggest a legitimate file pattern that causes a false warning.
- Improve plain-language safety explanations.
- Fix accessibility, keyboard-navigation or mobile-layout problems.
- Suggest a security-guide topic based on a real question.

## Before opening an issue

1. Test the latest live version at https://armaanshashvat2014-dot.github.io/github-protect/.
2. Search existing issues for the same problem.
3. Remove all private data from screenshots and examples.
4. Include the browser, operating system, affected page and exact steps.

## Pull requests

Keep changes focused, explain the user-visible effect and test the relevant workflow. Do not add real malware, tracking without consent, public API keys or claims that browser analysis guarantees safety.

## Security reports

Do not publish passwords, tokens, personal files or working exploit details in a public issue. See [SECURITY.md](SECURITY.md).
