Emergency Security Guide

Choose what happened and act quickly without panicking.

Clicked a linkEntered a passwordDownloaded a fileAccount warning

I clicked a suspicious link

  1. Close the page and do not enter information.
  2. Check the browser’s downloads list for unexpected files.
  3. Open the real service by typing its official address yourself.
  4. If the page received any information, follow the relevant steps below.

I entered my password

  1. Go directly to the official website and change the password.
  2. Sign out other sessions and review recent account activity.
  3. Enable two-step verification using the official account settings.
  4. Change any other account that reused the same password.

I downloaded a suspicious file

  1. Do not open or run it.
  2. Remove it from Downloads and empty the system trash.
  3. Use the trusted security software already installed on the device.
  4. If it was opened, disconnect from sensitive accounts and ask a trusted adult or qualified technician for help.

I received an account-security warning

  1. Do not use links inside the warning message.
  2. Open the official app or website independently.
  3. Check signed-in devices, recovery information and recent activity.
  4. Report fake messages through the platform’s official reporting control.
