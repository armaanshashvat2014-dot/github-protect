How to Check an EXE File Before Opening It

Use this practical checklist to inspect an EXE download, verify its source and reduce risk before running it on Windows.

Do not run an unfamiliar EXE just to find out what it does. Inspection should happen before opening it.

1. Verify where the file came from

Return to the software publisher's official website by typing its address or using a trusted bookmark. Compare the download name, product version and publisher information with the page you expected. Downloads delivered through advertisements, shortened links, unexpected messages or copied websites deserve extra caution.

2. Read the complete filename

Enable file-name extensions in Windows File Explorer. Confirm that the name ends once in .exe. A name such as report.pdf.exe is an executable, not a PDF. Watch for misspellings, random characters and names that imitate system updates.

3. Check Windows properties

Right-click the unopened file and view Properties. Look for a Digital Signatures tab and compare the signer with the expected publisher. A valid signature improves confidence but is not a complete safety guarantee. An unsigned file is not automatically malicious, but it requires stronger verification.

4. Compare a published hash

If the publisher provides a SHA-256 value, calculate the downloaded file's hash and compare every character. Matching hashes show that the file is identical to the publisher's stated copy; they do not independently prove the publisher is trustworthy.

5. Scan before running

Use the trusted security software already installed on the computer. Keep its definitions updated. If it reports a warning, do not bypass it merely because the download page says the warning is “normal.”

Quick decision checklist

  • The download came from the verified publisher domain.
  • The complete filename and extension match what you expected.
  • The signer or publisher information makes sense.
  • A supplied SHA-256 hash matches.
  • Your installed security software reports no warning.
  • The website did not pressure you to disable protection.

If any important check fails, delete the download and obtain a fresh copy from the official source.
