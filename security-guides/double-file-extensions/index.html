How Double File Extensions Hide Dangerous Files

Learn how misleading names such as invoice.pdf.exe work, how to reveal the real file type and what to check before opening a download.

What is a double file extension?

A file extension is the ending that helps an operating system identify a file type. A misleading filename may contain a familiar extension in the middle and an executable extension at the end—for example, invoice.pdf.exe. The final extension controls the file type, so this example is an executable program rather than a PDF document.

Why the trick can be convincing

If an operating system hides known extensions, the visible name may appear to end with .pdf. Long filenames, extra spaces, unusual Unicode characters and familiar document icons can make the real ending easier to miss.

Extensions that deserve extra caution

Executable and script types include .exe, .msi, .bat, .cmd, .scr, .js, .vbs and .ps1. These formats have legitimate uses, but they should not be disguised as documents, images or invoices.

How to reveal the real type

  1. In Windows File Explorer, enable View → Show → File name extensions.
  2. Read the name from the final dot to the end.
  3. Open Properties without running the file and check its stated type.
  4. Do not trust the icon by itself.
  5. Scan the file using trusted security software before opening it.

Examples

  • photo.jpg — expected image extension.
  • photo.jpg.exe — executable using an image-like name.
  • statement.pdf.scr — screen-saver executable, not a PDF.
  • archive.zip.js — JavaScript file, not a ZIP archive.

When a filename is misleading, delete it and obtain the expected document from the verified sender or official service.
