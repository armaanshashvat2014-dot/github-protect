Can Browser Extensions Steal Passwords?

Learn how browser-extension permissions affect website data, what warning signs to inspect and how to remove risky extensions.

A browser extension can only do what its code and granted permissions allow, but some permissions are extremely powerful. An extension allowed to read and change data on websites may be able to observe information displayed or entered on those pages. That makes publisher trust, permissions and update history important.

Permissions that deserve attention

  • Read and change data on all websites: broad access across browsing sessions.
  • Manage downloads: visibility into downloaded items and the ability to initiate or control downloads.
  • Read browsing history: access to visited-page information.
  • Manage other extensions or browser settings: control beyond the extension's visible feature.
  • Clipboard access: potential access to copied information while the permission is active.

Warning signs

Be cautious when a simple extension requests broad permissions unrelated to its purpose, has an unknown publisher, copies a popular product's name, recently changed ownership, redirects searches, inserts unexpected advertisements or asks you to install software outside the browser store.

How to review an extension

  1. Open the browser's extension-management page.
  2. Read every permission and decide whether it matches the advertised feature.
  3. Restrict website access to specific sites or “on click” when possible.
  4. Remove extensions you do not use or cannot verify.
  5. After removal, review browser search, homepage and notification settings.
A browser-store listing reduces some risk but is not a permanent guarantee. Extensions can change through later updates.
